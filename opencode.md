# OpenCode — безкоштовний AI-агент для роботи з кодом

OpenCode — це open-source інструмент, який працює в терміналі і дозволяє AI-моделі бачити та редагувати твою кодову базу. По суті, це безкоштовний аналог Claude Code.

## Що він вміє

- Аналізувати проєкт: бачить файли, структуру, типи, імпорти
- Редагувати кілька файлів одночасно
- Виконувати команди в терміналі
- Працювати з git

## Чому безкоштовно

OpenCode — це лише оболонка (harness). Сам він не містить AI-моделі. Ти підключаєш будь-якого провайдера, включно з безкоштовними:

- **Google Gemini** — безкоштовний API-ключ через [Google AI Studio](https://aistudio.google.com/)
- **Groq** — безкоштовний тір
- **Ollama** — локальні моделі на твоєму компʼютері

## Встановлення

```bash
npm install -g opencode-ai
```

## Як користуватись

1. Відкрий термінал у корені свого проєкту
2. Запусти `opencode`
3. На першому запуску вкажи API-ключ (наприклад, від Google AI Studio)
4. Пиши промпт звичайною мовою — агент сам знайде потрібні файли, внесе зміни, встановить пакети
